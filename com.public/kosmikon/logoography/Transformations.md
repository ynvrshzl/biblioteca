# Operations of transformation

Symbols and transformation are the essential ideas in chronometrics.

| \#   | Opeartion           | Example             |     |     |
| ---- | ------------------- | ------------------- | --- | --- |
| \#   | coordinates         | \#a.aa.ba           |     |     |
| @    | cycle               | @ abcde @           |     |     |
| &    | repeat              |                     |     |     |
| %    | split               |                     |     |     |
| a(b) | variable definition | a (writing-project) |     |     |
| /    | hierarchy           | a/b/c               |     |     |
| !    | mark                |                     |     |     |
| .    | low                 |                     |     |     |
| -    | average             |                     |     |     |
| ^    | high                |                     |     |     |
| _    | placeholder         |                     |     |     |
| c    | complexity factor   |                     |     |     |
| x    | completion          |                     |     |     |
| ?    | chaos               |                     |     |     |
| >    | forward             |                     |     |     |
| <    | backward            |                     |     |     |
| =    | parallel            |                     |     |     |
| \|   | contrast            | a \| b              |     |     |
| \/   | filter              |                     |     |     |
| /\   | branch              |                     |     |     |
|      |                     |                     |     |     |
