but before getting into the social scale, I want to focus on what a computer really is, and how programming languages allow us human beings to express a form of pseudo language, in a space that is otherwise absolute perfect order; 
- a computer is an emergent structure of absolute logical rules, values, and properties bound by the laws of physics.
- programming languages allow such a high level interface to the computer, that we human beings can create things outside of its original design; like non-euclidean virtual worlds, high dimension mathematical simulation, and YouTube (lol).

it's almost as if we created a very primitive human nervous system, as mechanical, electrical substrate...

but without getting too deep into that philosophical idea of computation, the story I'm fascinated by, is essentially the history, the evolution from binary to video games. 

if we learn computer science as the holistic evolution, not just stopping short at computational accuracy, I believe we will have better engineering because more people will understand what computers really are, and how we can use them to solve real world problems. this is the major primary goal of the fields and tools I'm developing, and is one of the major motivations of these discussions.

if I were to build a new field of understanding, to study computers and to define things properly, we would have to begin proto-substrate; with the idea of logic itself.

what's interesting about logic, is that it's already a well-established branch of philosophy / mathematics... but it is not very useful to understand her computers work, because a computer utilizes a specific kind of logic; binary logic. and that originates from the physical constraint of electrical signal and components... but a computer is independent of substrate. that's actually a really important idea, because high level programming languages, are essentially virtual computers, which is a strange idea, but when we examine a seriously sophisticated programming system, like a video game engine, or a platform like youtube, we eventually realize; the sophistication of programming has exceeded the original design; raw computational instruction; at some point, the program is a computer itself...

... this is fascinating, because now, the smallest unit of computation, is no longer a logic gate, or a variable, but a concept, independent of substrate; and the smallest unit in computation, is signal. information. data. that's the thing that travels throughout the entire system, and somehow, it powers video, audio, interaction, logic, synchronization, calculation, and so many domains which we never truly get to appreciate when working with high level source. 

so I think the story of computation begins before the substrate; signal. information. data. now what's fascinating is that, logic gates model a more accurate map of computational space than programming, because they are physical, tangible, and completely constrained by their form; a logic gate can only have $n = f(T)$ possibilities (which my equation describes as basically, a logic gate type (T) can only have "n" possibilities.)

it turns out this is an incredibly important idea, because logic gates have measurable complexity; programming relies on structural complexity to be understood and useful... and it turns out, that's a very difficult balance. the story of computation, from binary to video games, eventually exhibits a phenomenon; we built systems that are more complex than we will ever truly understand, where we once relied on models of completeness, we can no longer deterministically predict what the system will do... it's at this point where we start seeing programming, even at the hardware level. like instruction sets for processors, modules that manage memory, multiplexers, etc. we start seeing abstraction, not merely at the physical level, but I'd be cognitive level; which is where programming lives.
