# Ontological philosophy of computation

This is a larger set of General Ontology

Computation exists as these states
- As finite automata
- As infinite, indefinite, non-finite potential
- As guided by an external source, system [^1]


[^1]: This is where the real world comes in. Problem-solving, features, ideas, extensions, improvements, optimizations etc.
