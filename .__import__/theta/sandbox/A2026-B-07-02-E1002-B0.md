### Essay on lazygit, text-based user-interfaces, and source 
[lazygit](https://github.com/jesseduffield/lazygit) is a strange technology, because it's a TUI inside the terminal, which mimics a GUI (only difference being it is keyboard driven). 

Ontologically, git is the source, there is nothing below the standard "git" commands set.

Git forms an alphabet of composable ideas, and requires efficiency. A graphical user interface abstracts that, (etymologically, this is the definition of the interface!)
