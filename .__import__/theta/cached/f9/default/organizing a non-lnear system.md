# Finding order in non-linear systems

Proposed titles: Survivng non-linear systems, Chaos Agency: "Sundial" - a Cognitive model for finding order in non-linear systems

## Abstract problem
"How do you organize a system with no way of knowing what is important?" This is a very significant issue. It is not only information

## Principle 1 - Linearize path
We must first establish a linear path to traverse hte non-linear system. 

For example, in our wiki system, instead of jumping between folders, we do the hard work of travelling from folder-by-folder, alphabetically. Paying equal attention to each object (file) as they hold ideas we want to further metabolize and refine (like space material mining in eve onlin)

## Using a wiki non-linear system as example
In this example, we use our own wiki, which is one of the most real-world examples of complexity and chaos: the system requires feedback in order to be manageable.

Information is inherently abstract: we depend on context to form meaning. A wiki system, as a large structure, is inherently the same function. We require a feedback system, and context.
