# Concluding research for Grammatica and Ergonomic language interfaces (ELIs)
luxonjs's syntax and api is incredibly well engineered; it's almost eerily similar to grammatica/meta-language;

new Object("constructor").arg("verb")

The power of this kind of constrained syntax is that; it removes the attention of the engineer from syntax design, to the power of objects and verbs themselves. This is what makes unix commands so powerful, arguably. But we see this quality severely deteriorate when we jump to scripting languages like bash; syntax makes the underlying program lost within translation.

That appears to be an important concept in language design; the patterns at structural level; not merely new additions, but understanding the minimal representation necessary for function (this is where Turing, Church, Lambda calculus, boolean algebra, and even math, become incredibly important resources for the ergonomic design of this language/family of languages.)
