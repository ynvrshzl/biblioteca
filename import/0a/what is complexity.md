## Exhibit A: Tracking Complex objects & Relata

Complexity is not only the explosion of details, but how we process those details, and how we form categories of relata.

I can track $a \rightarrow b \rightarrow c$ ...It is linear, it fits in periphery. It is memorizable. It is trackable. If individaul parts change or lead to cascading effects, we know the position and cause. In essence, it is a closed system; and we have epistemic control (via understanding and vision). No interacting parts or relationships, contain hidden features. This is as simple as a cohesive closed system can be.

However, there is almost never a closed system in real life. I cannot easily track 

$$
	z \rightarrow x, a \rightarrow b \leftarrow c \\
	x = [a,b,c], z =[d,e,f] \\
	a = [0,1,2], c = [3,5,2], b = [0,1,5]
$$

There are several moving working dynamic parts, several relationships are hidden, it is not affordably linear, there are several orders of abstraction at several scales, and changing one part will almost surely cascade unpredictably. This system is unredable, without a memory map.

Now let's understand how complexity actually emerges, why it is essential (and not the same as chaos; i.e., not the enemy)
