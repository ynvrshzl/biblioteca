What if instead of organizing information via content then files, then...

we organzed it in a map?

What if instead of convoluted links and URL paths, we could find and store things by address, lcoation: e.g.,

(100, 15.3.125, 0.35)

this parameter schema would fit several conceptual frames:
- (x, y, scale)
- (row, column, ...)
- (width, height, depth)
- (pitch, yaw, ...)

the most useful appears to be (x,y,z(zoom/depth))
