A brief introduction to the project and it's interconnected map structure.

This project assumes a non-linear, text-based adapted-zettelkasten. In essence, rather than relying on complex build stages, UI/UX design, or web technologies, the system is entirely authored in plaintext; these files are viewable from any text editor.
