# Chronometrics
Hierarchical categorization using "Prototype Theory"

For example, the first letters of "Physics" can be variable-ized as "Ph" and it's corresponding coordinate 


```
Physics, Computer Science, Productivity, Health, Christianity.
^        ^        ^        ^^            ^       ^                                   
P        C        S        Pr            H       C
```
