## Software Engineering is not writing code
Code is essentially our instruction of executable causality. Software Engineering, is structural and architectural; it is less about instruction and more construction

Code somehow became about execution and prorotyping first, with little to no regard on the architecture of the systems being constructed. As a result, we see countless pieces of software resembling absolute chaos: wires, cables, or the famous "Sphagetti code." What does that do to the human engineer, having to navigate volatile enviornments, often, for hours on end, entirely cognitive? What does it do the the person using the software?

This isn't arguing a perfect form of computer
