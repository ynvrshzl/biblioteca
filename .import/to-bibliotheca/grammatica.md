## Abstract
What is a major problem with overly verbose languages? Mathematics uses symbols, Chemistry uses notation,

Here are all 50 alpha-numeric symbols, available on most standard keyboards, making it adequate for a wide application of language-based tools. From symbolic code (lexica), to systems grammar (grammatica)

```plaintext
1234567890 
!@#$%^&*()_-+=[{}] /|/ /|\ ,<>`~. ;: ' "  <>
```

## Exploring the pros of symbols
### Composition & Compression
Symbols can be composed, For example, we may create an array memory hashmap like this

```plaintext
+#
```

Or the same symbol, may be reversed to produce alternative meaning

```plaintext
#+
```

This is a linguistic function of natural language

## Exploring programming concepts as symbols

To assign a name to memory, we can define it as

```plaintext
+# (var)
```

